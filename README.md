# 恋爱纪念册小程序

基于 `https://love.xpigm.com/` 的核心体验重新实现了微信小程序版，并针对小程序场景做了适配与功能改造。

## 已实现功能

- 沉浸式首页：保留“恋爱计时器 + 情话 + 纪念氛围”的核心体验
- 小程序化改造：去掉网页依赖的 Bootstrap、jQuery、Valine 评论和外部动画脚本
- 留言墙：使用本地存储保存双人留言，适合微信端轻量使用
- 资料设置：支持自定义双方昵称、开始日期、城市、首页标题、承诺文案、主题
- 纪念片段：可新增、删除、恢复示例数据，用来记录关键节点
- 节日彩蛋：内置 520、521、情人节、周年纪念日、关键天数提示
- 分享文案：支持小程序分享标题和首页纪念文案复制

## 结构

- `pages/index`：首页
- `pages/wall`：留言墙
- `pages/settings`：资料设置与纪念片段管理
- `utils`：默认数据、本地存储、时间计算

## 使用方式

1. 用微信开发者工具打开当前目录
2. `AppID` 可先使用测试号或开发号
3. 如需上线，将本地存储数据替换为云开发 / 自建接口即可

## 适配说明

原网页版本依赖浏览器滚动、第三方评论系统和外部情话接口，小程序中已改造成以下方式：

- 评论区改为本地留言墙
- 情话接口改为内置语录库，避免接口不可用
- 节日彩蛋改为前端日期逻辑
- 页面布局改为更适合手机竖屏的小程序卡片式结构
